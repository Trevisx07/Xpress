# Image asset specification

Six supplied files carry every image on the site. Sources are in `images/` and are processed by `npm run prep:images`. Sizes are 2x the largest CSS box (container caps 1280 / 1440 / 1600 px, 64 px gutters at lg). Everything else is generated by a script from the logo.

Palette for photo grading: black `#0F1216`, steel `#1A1F27`, red `#E8121E`, chrome `#C9CDD3`. The hero carries a cool neutral duotone at 22% multiply, so keep the white truck and the red decal clean and avoid warm color casts.

## After replacing

Drop new sources into `images/` under the same names, then:

```bash
npm run prep:images
npm run gen:icons && npm run gen:og   # only if the logo changed
npm run build && npm run check
npm run audit
```

The build stops with `services: missing photo` if a `site.ts` image filename has no matching file.
